| slug | 제출 프레임명 | 등급 | 목적 | 필수 요소 | 근거 (PRD 원문 인용) |

| `S02-stock-detail` | `New/StockDetail` | **P0** | 종목 하나를 판단하고 그 자리에서 주문까지 끝낸다 | 가격 차트(기간 전환) / 현재가·등락 / 기본 정보 / 매수·매도 하단 고정 / 주문 시트 | "6-2. 종목 상세 `New/StockDetail`" |
| `S02b-order-sheet` | `New/StockDetail-OrderSheet` | **P0**(6-2의 명시 요소) | 수량·가격 입력 후 주문 확정 | 수량·가격 입력 / 예상 금액 / 주문 확정 | "**별도 화면이 아니라 이 화면 위에 올라오는 형태로** 만들어주세요" |

| `S05-sort-sheet` | `New/Watchlist-SortSheet` | P2 | 정렬·필터 진입점의 목적지 | 정렬 기준 목록 / 적용 | "정렬 또는 필터 **진입점**" (진입점 → 목적지 규칙) |

### 상태 환원 (유저스토리·상황 절 → 화면)

| PRD 원문 인용 | 환원 결과 | 등급 |
|---|---|---|
| "관심종목이 비어 있으면 아무것도 시작되지 않습니다 → **이게 가장 큰 이탈 지점**" | 관심종목 **빈 상태** | **P1** (플로우 차단) |

| "장 시작 직후에는 **시세가 아직 들어오지 않는** 몇 초가 있습니다" | 시세 **로딩 상태** | P3 |
| "주문을 넣었는데 **잔고가 모자라거나 장이 닫혀** 실패하는 경우가 있습니다" | 주문 **실패 상태** | **P1** (주문 플로우 차단) |
| "**투자 스타일을 아직 고르지 않은** 사용자에게도 무언가는 보여줘야 합니다" | 스타일 **미설정 상태** | P1 |
| "관심종목은 평균 12개, 많게는 **200개**까지" | S01 리스트가 **길이에 안 무너지는 구조**여야 함(Auto Layout 근거) | — (구조 제약) |

> P1·P3 상태는 **화면마다 만들지 않고** `S04-states` 1장에 4분할로 통합한다.

## 플로우

```
S03-discover ─(종목 탭)─┐
S01-watchlist ─(행 탭)─→ S02-stock-detail ─(매수 탭)─→ S02b-order-sheet ─(확정)─→ [성공|실패→S04]
S01-watchlist ─(정렬)──→ S05-sort-sheet
S01(빈 상태) ─(종목 찾아보기)─→ S03-discover
```

## 다음 단계가 이 파일에서 뽑아 쓸 것

- ②: `assetPage` = `1-daangn`, `doNotRead` = `2-airbnb`
- ④: 화면 인벤토리 전체 (필수 요소가 스펙의 체크리스트가 된다)
- ⑤: 제출 프레임명 + 등급(저작 순서 = P0 → P1 → P2)
- ⑦: **P0 프레임명 4개**(`New/Watchlist`·`New/StockDetail`·`New/StockDetail-OrderSheet`·`New/Discover`)가 누락 검증 키
