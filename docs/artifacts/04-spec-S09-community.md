# S09-community — `New/Community` (동네 주식방)

**메뉴로 구성한다.** 증권 서비스의 4번째 축(홈 · 관심목록 · 발견 · **동네 주식방**).

## 왜 이 화면인가
- 토스증권의 **커뮤니티**는 종목별 토론이 활발한 핵심 기능이다.
- 당근의 **동네생활**은 이미 "이웃에게 묻고 답하는" 문법을 완성해 두었다.
  (실측: `동네소식 / 🙌 같이해요 / 동네질문 / 동네맛집 / 취미생활` + `공감하기 · 댓글쓰기`)
- 우리 퍼소나 결론: **"동네 사람들이 뭘 하는지 보고 소액으로 따라 시작하는 사람"**
  → 판단 근거를 커뮤니티가 만든다. **이 화면이 없으면 서비스의 절반이 없다.**

## 카테고리 (당근 동네생활 문법 그대로 — 이모지 + 짧은 명사)

| 칩 | 내용 | 당근 원본 대응 |
|---|---|---|
| 🏘 **우리동네 투자** | 동네 사람들이 요즘 뭘 사는지 | 동네소식 |
| 🙌 **같이 배워요** | 초보끼리 모여 공부 (N/M명 참여) | 🙌 같이해요 |
| 💬 **투자 질문** | "Q. …" 형식의 초보 질문 | 동네질문 |
| 🎉 **성공담** | 수익 인증·자랑 | 취미생활 |
| 😅 **실패담** | 물린 이야기·교훈 | — (신설, 당근 톤 유지) |
| 📈 **종목 이야기** | 종목 태그가 붙은 토론 | 동네맛집(대상별 이야기) |

## 프로필 태그 = 투자 스타일·분야 (당근 매너온도 옆자리)

`요우우 · 화양동 · 40.3℃ · 단기수익형 · 반도체`
- **투자 스타일**: 단기수익형 / 배당형 / 성장형 / 안정형 (PRD 4-2)
- **투자 분야**: 반도체 · 방산 · 2차전지 · 바이오 (PRD 4-3)
- 스타일·분야는 **작은 회색 pill**로. 온도는 기존 오렌지 pill 그대로.

## 섹션 구조

| # | 섹션 | 내용 |
|---|---|---|
| 1 | 헤더 | `동네 주식방` (28/800) + 우측 글쓰기 아이콘 |
| 2 | 지역 표시 | `군자동` ⌄ (당근은 항상 동네를 먼저 밝힌다) |
| 3 | 카테고리 칩 | 위 6개, 가로 스크롤. 선택=검정 배경 |
| 4 | **글 카드 리스트** | 아래 구조 |
| 5 | 플로팅 작성 버튼 | 검정 pill `✏️ 글쓰기` (당근 실거래가 화면의 플로팅 pill 문법) |
| 6 | 탭바 | 당근 5탭 (나의 당근 활성) |

## 금지
- "수익 인증", "○○% 수익 달성" 같은 **과시형 카피** → 당근 톤 아님 (담백하게)
- 종목 추천·단정 표현 ("지금 사세요") → 금지 (③ 금지 패턴)
- 손실 조롱·비난 → 커뮤니티 가이드 위반

## PRD 연결
- PRD 4-2 **투자 스타일** / 4-3 **선호 테마** → 프로필 태그·카테고리로 구현
- PRD *"사용자가 직접 고르게 하고, 그 선택이 추천에 실제로 반영되는 것처럼"* → 스타일 태그가 커뮤니티·추천 양쪽에 노출
