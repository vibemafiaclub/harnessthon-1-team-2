# ⑧ 에셋 채움 — "회색 사각형"을 없애는 단계

**왜 이 단계가 있는가.** 저작 단계는 레이아웃을 우선하느라 이미지·아이콘 자리를
**임시 도형(단색 사각형·원)** 으로 두고 넘어간다. 그대로 두면 완성도 점수가 즉사한다.
사람이 매번 눈으로 찾는 대신 **이 단계가 전수로 훑어 목록화하고 채운다.**

> 이 단계는 **저작(⑥)과 병렬로** 돈다. 저작이 화면 1개를 끝낼 때마다 그 화면을 검사한다.

## 입력 (이것만 읽는다)
- `docs/artifacts/exports/*.png` — 저작 결과 PNG
- `docs/artifacts/05-design-system-*.md` — 색·shape 토큰
- (선택) 저작 단계가 남긴 보드 구조 덤프

## 출력 (이것만 쓴다)
- `docs/artifacts/08-asset-manifest.md` — 플레이스홀더 목록 + 필요 에셋 스펙
- `docs/artifacts/assets/**` — 직접 생성한 SVG 아이콘

---

## 절차

### 1. 플레이스홀더 탐지 (전수)
각 화면 PNG를 보고 아래를 **좌표와 함께** 찾는다.

| 유형 | 판별 기준 |
|---|---|
| **이미지 슬롯** | 단색 면(회색·연한 톤)이 40×40 이상이고 그 안에 아무 형태도 없음 |
| **임시 아이콘** | 16~48px 단색 사각형/원이 텍스트 옆·탭·버튼 안에 있음 |
| **깨진 아이콘** | 아이콘 자리가 비었거나 라벨만 있음 |
| **로고 자리** | 리스트 행 좌측의 빈 원/사각 |

각 항목에 **`화면 · 위치 · 용도 추정 · 필요 크기`** 를 적는다. 추정 용도는 **인접 텍스트**에서 가져온다
(예: 옆 라벨이 "항공"이면 → 비행기 아이콘).

### 2. 아이콘 조달 — 검색 우선, 없으면 생성
1. **기존 자산 재사용**: `docs/artifacts/assets/` 에 이미 같은 의미의 아이콘이 있으면 그것을 쓴다(중복 생성 금지).
2. **없으면 직접 SVG 생성**. 규칙:
   - 선 아이콘: `viewBox 0 0 24 24`, `stroke-width 1.8`, `linecap/linejoin round`, `fill none`, 색은 `currentColor` 또는 토큰 색
   - 면 아이콘: 2톤 이내, 토큰 색만
   - 파일당 단일 `<svg>` 루트, 외부 참조·폰트 임베드 금지
   - 파일명 `ic-{의미}.svg` / `cat-{분류}.svg` / `tab-{탭}.svg`
3. **사진성 이미지**(숙소·풍경·인물)는 직접 만들지 말고 **매니페스트에 발주 항목으로만** 적는다
   (이미지 생성은 별도 담당). 크기·비율·톤·금지사항을 명시한다.

### 3. 매니페스트 작성

```markdown
## 플레이스홀더 (탐지)
| 화면 | 위치 | 현재 | 용도 추정 | 필요 스펙 |
|---|---|---|---|---|
| TravelHome | 카테고리 1행 | 26x26 파란 사각 | 국내숙소 아이콘 | 56x56 면 아이콘 |

## 생성 완료 (SVG)
| 파일 | 의미 | 적용 대상 |
|---|---|---|

## 발주 필요 (사진)
| 파일명 | 크기 | 내용 | 톤 | 금지 |
|---|---|---|---|---|
```

### 4. 적용 요청
직접 Penpot에 넣지 않는다. 매니페스트에 **적용 대상(보드·요소 이름)** 을 적어 저작 단계가 삽입하게 한다.
(Penpot 플러그인 연결은 1개뿐이라 동시 저작하면 전부 실패한다.)

## 금지
- **Penpot 접근 금지** (저작 단계 전용)
- 이미 있는 아이콘을 다시 만들지 않는다 — 먼저 `assets/` 를 훑는다
- 토큰 밖의 색을 쓰지 않는다
- 사진성 이미지를 SVG로 억지로 그리지 않는다 (발주 항목으로만)
- 이미지 안에 글자를 넣지 않는다 (텍스트는 저작 단계가 얹는다)
