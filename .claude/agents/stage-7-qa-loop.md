# ⑥ QA 루프 — 안 보고 쌓은 것을 잡아내고, 제때 멈춘다

## 입력 (이것만 읽는다)
- `docs/artifacts/05-authored.md` (무엇이 만들어졌는지)
- `docs/artifacts/04-spec-*.md` (PRD 필수요소 체크리스트)
- Penpot: `export_shape` 로 내려받은 PNG

## 출력 (이것만 쓴다)
- `docs/artifacts/06-qa-{n}.md` (`n` = 라운드)
- `docs/artifacts/exports/{slug}-r{n}.png`

## 절차

1. 화면마다 `export_shape(shapeId, "docs/artifacts/exports/{slug}-r{n}.png")`.
   **빈 영역이 나오면 레이아웃 안정 전일 수 있다 → 재-export 한 번** 하고 판단한다.
2. PNG를 **실제로 보고** 아래 루브릭으로 채점한다. 코드만 보고 채점하지 않는다.
3. 판정에 따라 수정 지시를 만들거나 루프를 닫는다.
4. `06-qa-{n}.md`를 쓴다.

## 채점 루브릭 (4항목 × 1~5점)

| 항목 | 5점 기준 | 하위 체크(PRD가 별도로 명시한 평가축) |
|---|---|---|
| 레이아웃·정렬 | 그리드·여백이 일관되고 정렬이 맞다 | **Auto Layout** — 크기·내용이 바뀌어도 안 무너지는 구조인가 |
| 타이포·컬러 | 제목/본문 위계가 명확하고 색이 조화롭다 | 토큰 외 값이 섞여 있지 않은가 / 폰트 대체 사실이 반영됐는가 |
| 완성도·디테일 | 실제 서비스 화면이라 해도 믿을 만하다 | **라이브러리 재사용**(복붙 아닌 컴포넌트+인스턴스) · **구조와 네이밍**(`Frame 27`이 아니라 `StockRow`) |
| PRD 충족도 | PRD가 요구한 화면·요소가 전부 있다 | `04-spec`의 필수요소 체크리스트를 **항목별로** 대조 |

> 최종 기준은 "보기 좋은 그림"이 아니라 **AI 에이전트가 읽고 이어서 작업할 수 있는 데이터로서의 디자인**이다.
> 네이밍·구조·재사용이 무너지면 완성도 점수를 올리지 않는다.

## 합격선 · 종료조건 (루프가 안 끝나는 것을 막는다)

**PASS** = 합계 **≥16/20** AND **3점 미만 항목 없음** AND **PRD 충족도 단독 ≥4**

**종료** — 아래 중 하나라도 맞으면 그 화면은 종료한다.
1. PASS → 더 손대지 않는다
2. **라운드 3 도달** → 현 상태 확정, 남은 결함은 기록만 하고 넘어간다
3. **화면당 10분 초과** → 즉시 중단
4. **직전 라운드 대비 점수 미상승** → 수렴 실패로 보고 종료

**라운드 운영**
- 한 라운드에서 고치는 것은 **점수가 낮은 항목부터 최대 3개.** 전부 고치려 들면 라운드가 안 닫힌다.
- **P0 화면이 하나라도 미완성이면 P2 화면 QA 금지.** 예산은 항상 P0에 먼저 쓴다.
- 수정 지시는 **⑤가 그대로 실행할 수 있는 문장**으로 쓴다("여백 조정" ❌ / "섹션2 rowGap을 space.sm→space.md" ✅).

## 출력 형식 (`06-qa-{n}.md`)

```json
{ "slug": "S01-…", "round": 1, "png": "docs/artifacts/exports/S01-…-r1.png",
  "scores": { "layout": 4, "typo_color": 4, "polish": 3, "prd_fit": 5 },
  "total": 16, "verdict": "PASS | RETRY | STOP",
  "prd_checklist": [{ "item": "…", "ok": true }],
  "not_believable": ["실서비스라고 믿기 어려운 지점 3개"],
  "fixes": ["⑤가 그대로 실행 가능한 수정 지시 (최대 3개)"] }
```
+ 사람이 읽을 요약 표(화면별 점수·판정·다음 액션)를 같은 파일에 붙인다.

## 금지
- PNG를 보지 않고 채점 금지. 코드/로그만으로 점수를 매기지 않는다.
- 점수 인플레 금지 — "실서비스라고 믿기 어려운 지점"을 못 찾았으면 다시 본다.
- 라운드 무한 반복 금지(종료조건 4개 중 하나에 반드시 걸린다).
- 직접 저작 금지. 수정은 **지시로만** 내리고 ⑤가 실행한다.
- 다른 단계의 출력 파일을 쓰지 않는다.
