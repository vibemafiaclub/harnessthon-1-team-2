## `New/StockDetail-OrderSheet` (같은 화면 위 오버레이)

PRD: *"별도 화면이 아니라 이 화면 위에 올라오는 형태로 만들어주세요"*

- 만드는 법: `New/StockDetail`을 **`clone()`** → 이름 변경 → **뒤 화면 보드 `opacity` 0.4**
  (반투명 스크림 rect는 렌더에서 사라진다) → 그 위에 시트 보드를 얹는다.

| # | 시트 섹션 | 요소 | 실데이터 |
|---|---|---|---|
| 1 | 핸들 + 타이틀 | "매수 주문" | — |
| 2 | 수량 입력 | − / 수량 / + · 최대 가능 | "10주" / "최대 168주" |
| 3 | 가격 입력 | 지정가 · 현재가 버튼 | "74,200원" |
