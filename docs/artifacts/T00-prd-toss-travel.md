# PRD — 토스 여행 (Toss Travel)

작성: 2026.08.01 · 포맷: 박소현 5부 PRD · 근거: `3-toss` 자산 **실측**(452 shapes / 94 texts / 4화면)

---

## 1. 배경 및 목적

### 1-1. 배경
- 토스는 **송금 → 자산관리 → 결제 → 투자**로 확장해 온 금융 슈퍼앱이다.
- 자산 실측 IA: 하단 5탭 **홈 · 혜택 · 토스페이 · 주식 · 전체**
- 홈은 계좌 카드 리스트(토스뱅크·하나·우리·카카오뱅크·**저금통**)에 각각 `송금` `잔액보기` 액션.
- 혜택 탭에는 **포인트·이번 주 미션·행운복권·만보기·라이브 쇼핑·공동구매**가 있다.

### 1-2. 왜 토스가 여행을 하는가 (자산 IA에서 도출)

| 자산 실측 근거 | 사업 논리 |
|---|---|
| `저금통` (홈 계좌 리스트) | **여행 자금을 모으는 그릇**이 이미 있다 |
| `토스페이` (단독 탭) | 결제 수단·간편결제가 **이미 앱 안**에 있다 |
| `소비 · 새 내역 9건` | 결제 후 **지출 기록이 자동으로** 남는다 |
| `혜택` 탭 (포인트·미션·복권·만보기) | **할인·적립 엔진**이 이미 돌아간다 |
| `토스프라임` (설정) | 구독 번들에 여행 혜택을 얹을 수 있다 |
| `주식`·자산 연결 | 큰 금액 결제에 대한 **신뢰**가 형성돼 있다 |

**⭐ 핵심 경로 — 이 서비스의 존재 이유**

```
저금통으로 여행 자금을 모은다 → 토스페이로 예약·결제한다
   → 소비 내역에 자동 기록된다 → 혜택 탭에서 포인트로 돌아온다
```

- 여행 앱(야놀자·여기어때·NOL)은 **결제 순간만** 가진다. 금융 앱은 **예약이 없다**.
- 토스만 **돈의 흐름 전체**(모으기 → 쓰기 → 기록 → 되받기)를 가진다. 이건 복제가 어렵다.
- ⇒ **첫 화면 최상단은 "특가 배너"가 아니라 "여행 자금 + 오늘의 이득"이어야 한다.**

### 1-3. 목적
- 여행을 **"떠나는 일"이 아니라 "돈을 모으고 아끼는 일"** 로 다시 정의해, 토스 사용자의 기존 습관 위에 얹는다.

### 1-4. 타깃 퍼소나 (자산 실측 기반)

| 유형 | 특징 | 근거(자산 원문) |
|---|---|---|
| **주요** 20–40대 토스 헤비유저 | 매일 앱을 열어 **소액 리워드**를 챙긴다. 송금·소비확인이 습관 | `행운복권` `만보기 130원 받기` `이번 주 미션` `얼마 받을 지 보기` |
| **보조** 30–50대 자산관리형 | 계좌 4개+저금통을 연결해 자산을 본다. 큰 결제를 앱에서 한다 | 홈의 계좌 카드 5개, `마이데이터 자산 연결` |

> **한 문장**: 이 사용자는 *"여행지를 검색하는 사람"* 이 아니라
> **"이번 여행에 얼마 쓰고 얼마 돌려받는지 계산하는 사람"** 이다.

## 2. 솔루션 및 기능

### 2-1. 핵심 솔루션
> **여행 자금을 모으는 순간부터 결제·적립까지 토스 안에서 끝낸다.**

### 2-2. Feature List

| 기능 | 설명 | 우선순위 | 근거 |
|---|---|---|---|
| 여행 홈 | 여행 저금통 잔액 + 오늘의 이득 + 특가 + 카테고리 | `High` | Why 핵심 경로 |
| 숙소 검색·지도 | 지역·날짜·인원 + 지도 마커 + 목록 | `High` | NOL 레퍼런스 |
| 카테고리(호텔·리조트) | 지역선택·테마·특가·라이브 | `High` | NOL 레퍼런스 |
| 숙소 상세·예약 | 정보 행·리뷰·하단 2버튼 | `High` | 토스 상품상세 문법 |
| **여행 저금통** | 목표 금액·D-day·자동 모으기 | `High` | 자산 `저금통` |
| **토스페이 결제 + 적립** | 결제 시 포인트 즉시 적립 표시 | `High` | 자산 `토스페이`·`혜택` |
| 여행 포인트 미션 | 출석·룰렛·리뷰·친구초대 | `Medium` | 자산 `혜택` 탭 |
| 소비 내역 연동 | 여행 지출이 소비 탭에 자동 분류 | `Medium` | 자산 `소비` |

## 3. 서비스 구조

### 3-1. IA — 기존 구조를 갈아엎지 않는다

**기존 글로벌 내비(실측, 변경 금지)**: 홈(41) · 혜택(108) · 토스페이(177) · 주식(257) · **전체(332)**

**신규 진입 경로**
```
전체  →  여행                         (탭을 6개로 늘리지 않는다)
         ├─ 여행 홈      New/TravelHome
         ├─ 검색·지도    New/TravelSearch
         ├─ 카테고리     New/TravelCategory
         └─ 숙소 상세    New/TravelDetail  →  결제(토스페이)
```
- 여행 화면에서도 하단은 **토스 5탭 유지**, `전체` 활성.
- 여행 내부 이동은 **상단 pill 탭**(여행 홈 / 국내숙소 / 해외숙소 / 항공 / 특가) — 토스 쇼핑 홈과 동일 문법.

### 3-2. 어휘 (기존 용어 우선)
| 일반 여행앱 | 토스에서 |
|---|---|
| 마이페이지 | **전체** |
| 적립금·마일리지 | **포인트** |
| 결제하기 | **토스페이로 결제** |
| 여행 적금 | **여행 저금통** |
| 찜 | **찜** (유지) |

## 4. 디자인 전략

### 4-1. 레퍼런스 — 무엇을 왜 차용하는가

| 레퍼런스 | 차용 | 왜 |
|---|---|---|
| **토스 자산(3-toss)** | 5탭 IA · 카드 리스트 + 행 액션 · 색 · 폰트 · radius 20 | 같은 제품으로 읽혀야 함 |
| **토스 쇼핑** | 전폭 검색필드 · **연회색 pill 상단탭** · 연블루 배너카드(+`2\|9` 인디케이터) · 포인트 섹션 + 파란 뱃지 · 하단 2버튼(연블루 장바구니 / 파란 filled 구매) | 토스가 이미 만든 **커머스 문법** — 여행도 커머스다 |
| **토스 상품상세** | 라벨(회색)/값/`›` 정보 행 · 회색 밴드 섹션 구분 · 리뷰 탭 언더라인 · 별점 강조 | 예약 상세에 1:1 대응 |
| **NOL(여행앱)** | 검색카드(지역·날짜·인원) · 5×2 카테고리 그리드 · 지도 마커(가격) · 목록 FAB · 테마 원형 캐러셀 | 여행 도메인 관습 — **레이아웃만** 차용, 색·타이포는 토스 토큰 |

### 4-2. GUI 방향 + 왜

| 원칙 | 내용 | 왜 |
|---|---|---|
| 1 | **첫 화면 최상단 = 여행 저금통 + 오늘의 이득** | Why 핵심 경로. 특가로 시작하면 그냥 여행앱 |
| 2 | 강조색 **#4880EE 하나**, 면적 큰 곳은 연블루 `#E9F1FE` | 자산 실측(면적가중 1위) |
| 3 | **숫자를 크게, 문장을 짧게** | 퍼소나 = 금액을 계산하는 사람 |
| 4 | 과장 금지 — "❗최대 76%" 대신 **"49,000원 · 조식 포함"** | 토스 톤은 담백·정확 |
| 5 | 카드는 radius 20, 버튼·칩은 full round | 자산 실측 + M3 shape |

**UX 라이팅(토스 실측 차용)**: `~해요` 종결 · `얼마 받을 지 보기` 처럼 **행동+결과** · `누르면 바로 10원 받아요` 처럼 **즉시 이득 명시** · 과장·명령형 금지

### 4-3. 디자인 시스템 = **Material 3 × 토스 토큰**
- color role: primary `#4880EE` / primary-container `#E9F1FE` / on-surface `#17171B` / on-surface-variant `#62626C` / outline-variant `#E4E4E5` / surface-container `#F2F4F6`
- type scale: displayS 36 · headlineS 24 · titleL 22 · titleM 16 · bodyL 16 · bodyM 14 · labelL 14 · labelM 12
- shape: card **20**(자산 실측) · sheet 12 · chip/button **full**
- spacing: **좌우 16 고정**, 섹션 24~32, 4dp 그리드
- Navigation bar 80 + **활성 pill 인디케이터**
- 폰트: **Spoqa Han Sans Neo**(자산 실측 폰트, 무료 배포판 업로드)

## 5. 기술 스펙 (High 기능만)

| 기능 | DB | API | 주의 |
|---|---|---|---|
| 여행 저금통 | `TravelSaving(user, goal, balance, dday, auto_rule)` | `GET /travel/saving` `POST /travel/saving/auto` | 기존 저금통 스키마 재사용 |
| 숙소 검색 | `Stay(id, name, type, geo, price, rating)` | `GET /stays?region&from&to&pax&sort` | 지도 마커는 **클러스터 집계** 필요 |
| 예약·결제 | `Booking(user, stay, dates, pax, amount, status)` | `POST /bookings` → 토스페이 결제 위임 | 실패코드 `SOLD_OUT`·`PAY_FAILED` |
| 포인트 적립 | `PointLedger(user, source, amount)` | `POST /points/earn` | **결제 화면에 적립 예정액 선표시**(퍼소나 동기) |
| 소비 연동 | 기존 `Spending` | `POST /spending/tag` | 여행 카테고리 자동 태깅 |
