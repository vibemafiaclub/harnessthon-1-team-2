# ④ 화면 스펙 — ⑤가 코드로 옮기기만 하면 되는 수준까지 내린다

## 입력 (이것만 읽는다)
- `docs/artifacts/01-screens.md`
- `docs/artifacts/02-tokens.md`
- `docs/artifacts/03-reference.md`

셋 중 **하나라도 없으면 즉시 중단하고 무엇이 없는지 보고**한다. 추측해서 채우지 않는다.

## 출력 (이것만 쓴다)
- `docs/artifacts/04-spec-{slug}.md` — **화면 1개당 1파일**
- `docs/artifacts/04-components.md` — 화면들이 공유하는 컴포넌트 명세 1파일

## 절차

0. 🔴 **③의 Why·IA 전략을 먼저 적용한다.** (이걸 건너뛰면 "색만 같은 남의 앱"이 나온다)
   - **첫 화면 최상단 섹션 = ③의 Why 핵심 경로**를 눈에 보이게 만든 것이어야 한다.
     일반적인 도메인 관습 섹션(시장 지수·인기 순위 등)을 최상단에 두지 않는다.
   - **글로벌 내비는 ②가 추출한 실측 라벨·순서를 그대로** 쓴다. 지어내지 않는다.
   - **용어는 기존 어휘 사전 우선.** 같은 뜻의 단어가 자산에 있으면 그것을 쓴다.
   - 자산의 **공통 정보 축**(지역·시간·신뢰도 등)을 신규 리스트 행에도 유지한다.
1. ①의 화면 인벤토리에서 **P0 → P1** 순으로 처리한다. **P2는 P0·P1 스펙이 전부 끝난 뒤에만.**
2. 화면마다 **섹션을 위에서 아래로** 나열한다. 각 섹션에 다음을 지정한다.
   - 역할 · 포함 요소 · **레이아웃 방식** · **참조할 TOKENS 키** · 실데이터 예시 텍스트
3. **레이아웃은 Auto Layout을 기본으로 명시**한다(PRD 평가 항목).
   - 세로로 쌓이는 섹션/리스트 → `flex column` + `rowGap: TOKENS.space.*`
   - 좌우 배치 → `flex row` + `justifyContent`
   - **절대좌표는 오버레이·플로팅 요소에만** 허용하고, 그 경우 사유를 적는다.
4. **반복 요소는 컴포넌트로 승격**한다(복붙 금지 — PRD "라이브러리 재사용" 항목).
   - `04-components.md`에 `YS-{PascalName}` 으로 정의하고, 화면 스펙은 **인스턴스로 참조**한다.
   - 데이터만 다른 행은 **인스턴스 + `characters` 오버라이드**로 명시한다.
5. **실데이터를 쓴다.** "Lorem ipsum"·"텍스트1" 금지. PRD의 도메인에 맞는 그럴듯한 값
   (숫자·단위·날짜 포함)을 넣는다. 숫자는 PRD가 제시한 값이 있으면 **그 값을 우선**한다.
6. 각 화면 스펙 끝에 **PRD 필수요소 체크리스트**를 그대로 옮겨 붙인다(⑥이 PRD 충족도 채점에 그대로 쓴다).
7. 상태 화면(P3)은 개별 스펙을 만들지 않고 **`S9x-states` 1장에 통합 스펙**으로 쓴다.

## 출력 형식 (`04-spec-{slug}.md`)

```markdown
# {slug} — {제출 프레임명}
등급: P0 | 크기: TOKENS.artboard

## 섹션 구조 (위 → 아래)
| # | 섹션 | 레이아웃 | 요소 | 토큰 키 | 실데이터 예시 |
|---|---|---|---|---|---|
| 1 | 상단바 | flex row / space-between | 뒤로·타이틀·액션 | color.text, font.sizes[3] | "관심종목" |
| 2 | 리스트 | flex column / rowGap=space.sm | YS-StockRow ×5 | — | 종목명·현재가·등락률 |

## 사용 컴포넌트
- `YS-StockRow` ×5 (인스턴스, characters 오버라이드)

## 오버레이/상태 (있으면)
- 시트: 뒤 보드 opacity 0.4 + 시트 보드 상단 얹기 (반투명 rect 스크림 금지)

## PRD 필수요소 체크리스트 (⑥ 채점용)
- [ ] …
- [ ] …
```

## 출력 형식 (`04-components.md`)

```markdown
| 컴포넌트 | 구성(자식) | 레이아웃 | 토큰 | 가변 텍스트 |
|---|---|---|---|---|
| YS-StockRow | 로고·종목명·현재가·등락률 | flex row, 고정 폭 칸 | color.text/accent | 종목명·가격·등락 |
```

## 금지
- **토큰 값을 리터럴로 적지 않는다.** `#FF7E36`이 아니라 `TOKENS.color.accent`. (심사용 PRD에서 색이 바뀐다)
- 화면 전체를 절대좌표로 설계하지 않는다(Auto Layout 항목 0점).
- 반복 요소를 "복사해서 5개"로 적지 않는다. 컴포넌트+인스턴스로 적는다.
- PRD에 근거 없는 요소를 추가하지 않는다. 추가하려면 ①의 인용을 끌어와 근거를 붙인다.
- 다른 단계의 출력 파일을 쓰지 않는다.
