# [코덱스 지시] 컨셉 페이지 히어로 이미지 — 스플래시와 이어지는 컷

## 반려된 것
컨셉 페이지 히어로가 **검정 배경**이라 당근스럽지 않다. 당근은 밝고 따뜻한 톤이다.

## 만들 것 — `concept-hero.png` (PNG, 1080x900)
**splash-scene.png 의 "다음 컷"으로 읽히게 만든다.**

- splash-scene.png = 실내 거실 소파에서 이웃 3명이 태블릿을 함께 보는 장면
- concept-hero.png = **그 사람들이 창가/문밖 동네를 바라보는 컷** 또는 **같은 거실을 창 쪽에서 넓게 잡은 컷**
  - 창밖으로 illust-hero-story.png의 골목(주황 차양 가게, 화분들, 자전거)이 보이면 가장 좋다
  - 앞쪽 테이블 위에 작은 화분 하나와 폰이 놓여 있고, 폰 화면에 완만한 상승 곡선

## 필수 조건
- **3D 클레이(점토) 렌더** — splash-scene.png / illust-hero-story.png 와 **동일한 질감·조명·색감**
- 배경 톤: **밝은 크림/베이지** (검정 금지). 오렌지는 소파·차양 등 포인트로만
- **이미지 상단 25%는 밝은 크림으로 자연스럽게 페이드** (그 위에 흰 배경 텍스트가 얹힘)
- **이미지 안에 글자 절대 금지**
- 실존 인물·상표·캐릭터 금지
