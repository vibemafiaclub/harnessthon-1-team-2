### 2. 판정 기준 — "배경/면"과 "심볼"의 경계

정책을 아이콘 파일 안에서 집행하려면 경계 정의가 먼저입니다. 제안:

- **배경/면 = 심볼을 담기 위해 깔린 무의미한 판** (타일 전체를 덮는 원/사각) → **토큰만**
- **심볼 = 의미를 가진 형태** (비행기·건물·차·박스·집·지구본) → **다색 허용**
- 판별법: *그 도형을 지웠을 때 의미가 남는가.* 남으면 배경, 안 남으면 심볼.

### 7. 검증 도구 함정 (다음 회차가 같은 데 빠지지 않도록)

**ImageMagick 내부 SVG 렌더러는 `stroke` 를 누락합니다.** 최종 시트를 `magick -density 384` 로 뽑았을 때
`cat-abroad` 의 경위선과 `cat-tour` 의 접힘 점선이 **통째로 사라진 채** 렌더됐습니다(면은 정상).
그대로 보고했으면 "지구본이 민무늬 원이 됐다"는 허위 보고가 됐을 것입니다.

→ **SVG 시각 검증은 Chrome headless 로 합니다.** 실제로 쓴 명령:

```bash
# 10종을 흰 타일에 얹은 html 생성 후
"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless --disable-gpu \
  --hide-scrollbars --force-device-scale-factor=1 --window-size=1832,200 \
  --screenshot=out.png "file://.../final.html"
```

`qlmanage -t` 도 stroke 는 정상이지만 다건 반복 호출 시 **행(hang)** 이 관측됐습니다(2분 타임아웃).
치수 측정(`magick -trim`)만 래스터에서 하고, **형태 판정은 Chrome 렌더로** 하십시오.
